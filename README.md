# homemade_chess_game
Homemade chess game using pyArcade as the basis for the visuals. Planning to allow 2 players to connect via web browser.

# Package Installation (Linux)
1. Install python if you somehow don't have it.
2. Run {bash install.sh} to create the virtual enviornment and install packages from requirements.txt
3. Run {source venv/bin/activate} to activate your environemt
4. (Optional) Run {pip list} to display packages and check they match requirements.txt
